# Independent Footprint imbalance value styling

The official Footprint documentation describes cell outlines and value recoloring as independent choices: https://docs.luxalgo.com/platform/charts/order-flow/footprint (inspected 2026-11-04).

Each native Footprint instance now has **Recolor imbalance values**, separate from **Highlight imbalances** in Display. Side labels (Bid x Ask and Bid x Ask Trades, including the mode's automatic side labels) use displayed buy/sell flags for the optional tint in every profile mode. Filtered rows stay blank. Explicit false flags override legacy single-side annotations; simultaneous flags can tint both sides. Signed center Delta labels retain their existing sign colors independently of these controls. This change does not alter diagonal classification, means, filters, source rows or projected stacks.

Follow-up on 2026-11-05: new highlights and recoloring default off, with independent outline/text palettes, line width and a percent ratio input. Old explicit switches/colors migrate to preserve saved layouts. Centered values now use Ask-first imbalance recoloring rather than unconditional Delta sign colors. Native outline rectangles were aligned against the actual reference helpers. See `footprint-highlight.md`; its evidence supersedes the earlier default and outline behavior described by the original implementation below.

## Verification

- Seven cases in `tests/footprint-imbalance-style.test.ts` cover all four combinations on normal/inverted axes, side-volume/count labels across all five modes, Delta independence, dual/legacy/explicit-false flags, filtered slots, immutable sources, legacy active/disabled migration and strict native instance controls. Existing neutral-text tests now explicitly disable both controls. Full cells/layout/backup round-trip includes independent second/fifth-instance values.
- `tests/browser/footprint-imbalance-style.ts` with `scripts/verify-footprint-imbalance-style-browser.mjs` renders four identical explicitly simulated three-row profiles. Their nonzero diagonal comparisons yield the lower Sell and upper Buy flags; missing counterparts are excluded. Left to right: neither style, tint only, outline only and both. Screenshot: `artifacts/footprint-imbalance-style-comparison.png`. This validates application rendering, not pixel equality to Vela or market-data coverage.
- Focused tests: 58 passed across five files. Complete suite: **2,212 tests across 203 files passed** (`artifacts/footprint-imbalance-style-tests.log`). Standalone TypeScript and production build passed (`artifacts/footprint-imbalance-style-build.log`).
- Complete native app on an isolated loopback origin with ephemeral test authentication: after reload, Footprint 1 retained outline enabled / recolor disabled, while Footprint 2 retained outline disabled / recolor enabled. The recolor switch was toggled off/on in the scrolled 414 x 720 settings pane. Final console errors were empty. Screenshots: `artifacts/footprint-imbalance-style-settings.png`, `footprint-imbalance-style-mobile.png`. No real access credential was read or changed.

The overall Orderflow parity goal remains incomplete.
