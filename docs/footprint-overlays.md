# Standalone Footprint overlay indicators

The Indicators picker now supplies **Footprint** and **Visible Range Footprint** as native studies over the existing chart. Adding Footprint no longer switches the base chart to the Footprint price style. The chart-type switch remains available separately. Reference: https://docs.luxalgo.com/platform/charts/order-flow/footprint (inspected 2026-11-04).

Each study instance owns its settings, bounded execution collection, projections and source lifecycle. The per-bar overlay exposes one Footprint with the shared modes, raw/mean cell sizing, numeric choices, row grid, position, VA/POC, statistics, filters, imbalance styles, POC extensions, stacks and unfinished auctions. It does not paint duplicate side candles or introduce Footprint 2–5 tabs. The visible-range overlay aggregates the selected native candle slots and supports independent Left/Right alignment and width; it excludes all per-candle projections. Both reuse the existing painters and Shift-hover reader. Input labels are readable while resolvers also accept stored internal mode identifiers. Conditional controls follow the chart schema, and irrelevant generic price-source/line-style/axis-value controls are omitted.

Overlay color fields accept validated hex, RGB(A) and HSL(A) text, including alpha. The initial browser check exposed the old generic HTML color control's inability to edit transparent colors; these two studies now use the validated alpha-capable field instead.

The browser check also exposed dense manual rows disappearing with their numeric labels. The shared painter now retains positive-height histogram cells, bounds subpixel fills to their own row, and suppresses only unreadable numbers. Ordinary hover can read these painted dense rows; Shift additionally magnifies them. This applies to the chart type and both overlay variants.

## Sources and readouts

Only observed classified executions supply volume and underlying counts. Archive/live overlap is deduplicated by the shared FootprintHistory contract. Each native study subscribes only while active; generation fences prevent delayed callbacks after suspension, removal, resume or changed market context. Market/timeframe, archive revision and completed Replay boundary reset the collection. Replay without an eligible execution archive reports unavailable rather than fabricating a split from candles. Render channels are additionally checked against the owning chart's current source identity before painting.

Each native handle has a separate Data-window surface. Per-bar readouts retain the existing frozen inspection/CSV path, with overlay coverage provenance. Aggregate readouts use the full selected UTC window and observed/selected candle coverage; they are not captured as a single-candle inspection. Hidden/removed/source-stale surfaces cannot be read through another native handle or chart cell.
