# Visible-range Footprint chart section

The Footprint chart type now has a separate **Visible range** settings subsection. It adds an independently configured aggregate profile pinned to the right plot edge, alongside the five per-candle instances. Its width follows the plot width rather than candle zoom; the existing cell opacity remains constant at all zoom levels. Reference: https://docs.luxalgo.com/platform/charts/order-flow/footprint (inspected 2026-11-04).

The section has its own master toggle, width (5–90%, initially 30%), display mode, cell values, raw/mean sizing, row grid, VA/POC, imbalance-value/outline styles, statistics, filters and colors. Per-candle projections and side candles are excluded. The explicit native subsection uses the SDK's master gating, while all stored `vr*` fields go through strict layout/backup validation, including disabled profiles. Existing layouts remain valid and start disabled. Exact current Vela defaults and pixel geometry are not established by these application defaults.

## Calculation and provenance

Visible candle membership uses the native logical range, including partial edge candle slots. Replay admits completed selected candles only. `FootprintHistory.readVisible` aggregates those exact candle buckets from the one deduplicated raw execution tape. It does not sum filtered cells or per-candle averages, and it does not consume one of the five per-candle grids. Aggregate mean sizes divide aggregate side volume by aggregate known underlying trade counts; unknown counts poison that side. Filters, POC/VA and diagonal flags are then recomputed on the aggregate. The readout identifies observed/selected candle coverage, raw total/delta, selected UTC window and independent sizing/grid basis. Candles without observations do not become invented volume.

The single range cache keys tape revision, source-reset lifecycle, settings and selected candle membership. New/late executions, eviction, regridding and changed selections invalidate it. Its aggregate row map is separately bounded by the existing row limit, alongside the existing bounded five per-candle caches and shared 100,000-execution tape. Disabling the section frees its cache. The right-edge renderer and row hover reuse the same cells/geometry as per-candle Footprints, with an independent fixed-width lane and no stacked-zone, POC-extension or unfinished-auction projections.
