## Data contract

- Only validated, non-simulated Binance/Kraken/Hyperliquid `Tick` records with a known buy/sell side enter storage. Yahoo, unclassified IEX and simulated fallback ticks are excluded. Fixed record fields exclude unrelated object properties or credentials.
- A record's immutable identity is its **symbol + provider execution ID**. Duplicate arrivals, including concurrent browser-tab writers, do not add volume twice. A conflicting payload for an existing ID aborts the whole batch; it does not overwrite the earlier observation.
- IndexedDB holds at most **250,000 executions across all markets**, with **7-day event-time retention**. Oldest executions expire/evict automatically. Limits apply to individual observations, not guaranteed whole sessions/bars. Stats/reads apply the same expiry policy while recording is paused.
- The writer serializes batches of at most **1,000**, normally every500ms, behind a **5,000-execution pending bound**. Only transaction completion updates committed counters. Newly inserted records removed by retention in that same transaction are not counted as committed. Quota/write failures pause recording and retain the failed pending batch for retry. Backpressure stops accepting additional observations with a visible gap warning.
- UTC selections use exact millisecond **inclusive start / exclusive end** bounds. **Use stored market range** selects the inspected market's first timestamp through its last timestamp+1ms. Cancelled/obsolete reads cannot replace a newer selection, and a limited/corrupt read never returns a silently truncated export.
- Market summaries use indexed counts and first/last keys instead of materializing every stored trade. Query/export data is a frozen snapshot; the on-screen table previews only its final50 rows.
- Buy quantity, sell quantity and delta sum the canonical decimal spellings of the supplied numbers with BigInt intermediates. **JSON snapshot version2 uses decimal strings for totals**, preserving small increments beside large quantities without binary accumulation residue or final Number rounding. Individual trade fields retain the original typed tick values; no unknown upstream precision is reconstructed.
- CSV exports every selected execution's source symbol, ID, available exchange sequence, UTC time, price, quantity, aggressor side and `observed-only` coverage. JSON additionally retains the snapshot selection, totals and raw tick fields. Identical timestamps do not establish network arrival order; this is not an arrival-order Replay journal.

Recordings remain local IndexedDB data, separate from workspace backups/sync. Multiple tabs can observe the same market; their writes deduplicate, while each tab controls its own active recorder. Browser data eviction, tab suspension/closure, network interruptions, recording pauses and retention can leave gaps. Pending data can be lost at shutdown. `coverage: "observed-only"` never promises continuity, complete sessions or full exchange history. No archived event is published back into live quotes, alerts or paper fills.
