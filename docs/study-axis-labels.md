# Per-study price-axis values — 2026-10-30

**Values on the price scale** in a study's Style tab controls numeric plot value chips independently of host status-line values and the native Data window. Omitted legacy preferences mean enabled. Hidden/failed studies, a script's `display.priceScale` restrictions and global hidden axis labels suppress the chips. Native Volume, Session Volume Profile and VRVP have bespoke layers without eligible numeric plot series, so their dialogs do not offer this checkbox.

The painter reads each plot's exact last revealed slot minus the native calculation offset. It does not select the last non-null historical value or read a later projected Pine slot. Candle/bar plots use the current close; ordinary plots use their current point and color. Pane ownership, force-overlay, own-scale columns, inversion and coordinates come from Vela. Formatting delegates to the actual native axis formatter, including Percent, Indexed and volume units. Empty/unscaled and off-pane values are omitted.

Chips remain inside their pane and axis column, reserve room for the last-price/countdown chip and move to the nearest available vertical slot with a connector. If no slot fits, a chip is omitted; numerical Data-window values remain available. This is intentionally bounded collision handling, not a guarantee that every plot value can fit at every viewport size.

`scripts/patch-vela-study-axis-labels.mjs` installs a chrome painter seam in all five pinned Vela 0.9.0 bundles. Version and anchor-count guards reject incompatible packages, and repeated application is idempotent. The same chrome callback participates in native snapshots. Cleanup removes the callback/subscription. Neither the painter nor the preference changes series display masks, indicator inputs or autoscale membership. Main and satellite chart calculation signatures exclude both host presentation flags.

The optional boolean follows study instances through chart persistence, independent cells, layouts, templates and workspace backups. Recursive import validation rejects non-boolean values while accepting older backups without the field.
